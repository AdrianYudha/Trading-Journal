# Export XLSX & Success/Delete Animations

Versi ini menambahkan:

- Export `.xlsx` asli dari tombol Export Excel per bulan.
- Export `.xlsx` asli untuk semua data.
- Spreadsheet berisi judul laporan, ringkasan statistik, header kuning, border, alignment, warna status Win/Loss/BE/Running, freeze header, filter, dan lebar kolom yang sudah diatur.
- File dapat dibuka di Microsoft Excel dan ONLYOFFICE.
- Setelah Save berhasil, baris baru memberi efek success/flash hijau dan tombol berubah menjadi `✓ Tersimpan` sebelum baris masuk ke riwayat.
- Setelah Delete berhasil, baris memberi efek delete/flash merah sebelum menghilang.
- Toast success/error tetap muncul untuk memberi konfirmasi.

Tidak ada migration Supabase baru untuk fitur ini.
